# Bouts

## Abstract

A multiplayer stickman fighting game. Choose between five weapons and duke it out through the internet! 

## Features
- Choose bewteen five weapons
- Randomly selected maps every time
- Different skills per weapon
- Health
- Multiplayer and Lobby system
- Custom colors
- Physics based active ragdoll
- Mouse movement translates to force on the hand, so it feels like you're really putting force into the motion.


## Play

Head to my itch.io to play, or download the corresponding build. Please note: web can only work with web, and downloaded builds can only work with downloaded builds. Ex: Mac works with Linux, but Web can't connect to Windows lobbies.
